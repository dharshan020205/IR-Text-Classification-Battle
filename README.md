## Classification problem
Predict a news article's category from its headline and short description.
The initial experiment selects four categories with the largest class counts,
then uses a balanced sample of up to 10,000 documents per category.

The selected labels are determined from the actual downloaded file and saved
in `outputs/class_distribution.csv`; no performance numbers are pre-filled.

## Dataset download
1. Open https://www.kaggle.com/datasets/rmisra/news-category-dataset
2. Sign in to Kaggle and download `News_Category_Dataset_v3.json`.
3. Place the JSON file inside `data/raw/`.

Each record contains `category`, `headline`, `short_description`, and metadata.
The dataset has 210,294 records and 42 categories according to its Kaggle data card.

## Experimental protocol
- Same balanced four-class subset and same stratified 80/20 split for all models.
- Text = headline + short description.
- TF-IDF fitted on training data only; English stop-word removal, unigrams/bigrams.
- Decision Tree, KNN (cosine distance), Linear SVM, Multinomial Naive Bayes.
- Accuracy, macro precision, macro recall, macro F1, classification reports and confusion matrices.
- What-if: KNN with k = 3, 5 and 7, keeping data and TF-IDF fixed.

All metrics and graphs are generated by running the experiment on the downloaded dataset.
